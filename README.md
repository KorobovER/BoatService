# BoatService Admin

Административная панель для платформы управления мариной и бронирования мест стоянки водного транспорта.

Приложение позволяет централизованно управлять инфраструктурой марины, вести учёт судов, контролировать занятость мест и обрабатывать бронирования.

### Основные возможности

- Управление маринами и инфраструктурой.
- Учёт судов и их владельцев.
- Управление местами стоянки и отображение на карте.
- Календарь бронирований и контроль занятости.
- Управление пользователями и ролями.
- Авторизация и настройки профиля.

### Технологический стек

React, TypeScript, Vite, Chakra UI, TanStack Query, TanStack Router, Playwright, Docker.

### Мой вклад

Разработка frontend-части административной панели: реализация интерфейсов управления маринами, судами и бронированиями, работа с API, создание календаря бронирований и интеграция интерактивных карт.
